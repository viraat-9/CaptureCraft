# CaptureCraft

**Organize. Identify. Enrich. Preserve.**

A toolkit of safe file and photo utilities designed to simplify digital asset management.

CaptureCraft brings together practical utilities and workflows for organizing files, identifying duplicates, managing photo metadata, and keeping digital collections clean and consistent.

---

## ✨ Features

CaptureCraft aims to provide a collection of focused, reusable utilities:

| Utility | Description |
|---|---|
| 📁 File Organization | Sort, categorize, and organize files into structured directories. |
| 🔍 Duplicate Detection | Identify duplicate files and photos to help eliminate unnecessary clutter. |
| 🖼️ Metadata Management | Read, update, and manage image metadata, including EXIF information. |
| 🏷️ Tagging & Classification | Organize digital assets using meaningful attributes and classifications. |
| ⚙️ Workflow Automation | Combine individual utilities into repeatable file-management workflows. |
| 🛡️ Safe Operations | Prioritize data integrity and minimize the risk of accidental file loss. |

## 🎯 Project Philosophy

CaptureCraft is built around a few principles:

- **Safety first:** Protect original files and avoid destructive operations by default.
- **Transparency:** Make operations understandable and predictable.
- **Practicality:** Solve real-world file and photo management problems.
- **Modularity:** Keep utilities focused, reusable, and easy to extend.
- **Automation:** Make repetitive workflows easier to execute.
- **Data integrity:** Preserve important metadata and file attributes whenever possible.

CaptureCraft is designed to grow as a collection of independent utilities.

Each utility should ideally be usable on its own while remaining composable with other tools in the toolkit.

## 🔒 Safety Considerations

CaptureCraft prioritizes safe handling of user files.

The project aims to:

- Avoid modifying originals unless explicitly requested.
- Provide clear operation summaries.
- Support preview or dry-run workflows where practical.
- Avoid silently overwriting existing files.
- Preserve relevant metadata during supported operations.
- Make potentially destructive actions explicit.

Always maintain backups of important files before performing bulk modifications.
